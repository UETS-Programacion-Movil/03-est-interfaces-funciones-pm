# Semana 03 — Interfaces y Funciones en TypeScript (PM)

Programación Móvil · 3.° Bachillerato Técnico UETS (2026–2027).

Vas a resolver 2 retos (interfaces con puente Java y perfil/producto; funciones
tipadas con destructuración y carrito) y a grabar un screencast de 3 a 5 minutos
explicando tu solución con cámara y voz.

## Trabaja en Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/UETS-Programacion-Movil/03-est-interfaces-funciones-pm)

1. Haz **Fork** de este repositorio a tu cuenta.
2. Abre tu fork con **Codespaces** (botón verde `<> Code` → pestaña `Codespaces`).
3. Instala dependencias: `pnpm install`.
4. Corre las pruebas: `pnpm test`.
5. Verifica tipos: `pnpm run check`.
6. Abre el **Pull Request desde Codespaces** contra `main` del repositorio oficial.

## Entrega

- **Video Screencast (3 a 5 min):** rostro visible en cámara, voz explicando tu
  solución y demo de `pnpm test` y `pnpm run check` en verde. Pega el enlace en tu PR.
- Checklist:
  - [ ] `pnpm test` pasa al 100 %.
  - [ ] `pnpm run check` sin errores.
  - [ ] Video con cámara y voz, enlace pegado en el PR.
  - [ ] No modificaste archivos de `tests/`.
